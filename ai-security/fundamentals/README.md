# AI Security Fundamentals (AI 보안 기초)

AI 보안을 이해하기 위한 **기초 개념**을 다루는 하위 영역입니다.

AI 공격 표면(Attack Surface), 그리고 AI Security와 AI Safety의 구분 등을 정리합니다.
