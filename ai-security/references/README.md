# AI Security References (참조 정의집)

AI 보안 문서가 인용하는 표준·기관·프레임워크의 **정의집**입니다.
각 위협·점검 문서의 "참조" 블록에서 이 정의를 인용합니다.

## 참조 프레임워크 (기준 버전)

| 코드 | 프레임워크 | 기준 버전 | 상태 | 공식 출처 |
|------|-----------|-----------|------|-----------|
| OWASP-LLM | OWASP LLM Top 10 | 2026 | released (2026-08-04) | https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/ |
| OWASP-AISVS | OWASP AISVS | 1.01 | latest-stable | https://github.com/OWASP/AISVS |
| OWASP-ML | OWASP ML Security Top 10 | 최신판 | 확인 예정 | https://owasp.org/www-project-machine-learning-security-top-10/ |
| ATLAS | MITRE ATLAS | 최신판 | 확인 예정 | https://atlas.mitre.org/ |
| NIST-AI-RMF | NIST AI RMF | 1.0 | released | https://www.nist.gov/itl/ai-risk-management-framework |
| ISO-42001 | ISO/IEC 42001 | 2023 | released (유료) | https://www.iso.org/standard/81230.html |
| EU-AI-ACT | EU AI Act | — | released | https://eur-lex.europa.eu/eli/reg/2024/1689/oj |

> 각 버전은 공식 링크에서 확인할 수 있다. 유료 표준(ISO)은 원문을 옮기지 않고 명칭·역할·공식 링크만 둔다.
