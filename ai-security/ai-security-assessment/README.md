# AI Security Assessment (AI 보안 점검·평가)

AI 시스템을 실제로 **점검·평가·검증**하는 방법을 다루는 하위 영역입니다.
이 영역이 지식베이스를 단순 백과사전에서 **실무 점검 기준**으로 끌어올립니다.

- OWASP AISVS (기준 버전 1.01) 기반 검증
- AI Threat Modeling
- AI Security Testing / Red Teaming
- AI Security Checklist
- AI Security Assessment Report (보고서 양식)

> 콘텐츠 타입: `assessment` (rules-authoring §3.4 점검 템플릿). 각 점검 항목은 대응하는
> 위협 문서·참조와 상호 링크한다.
