# AI Security (AI 보안)

AI/ML 시스템의 보안을 다루는 **최상위 영역**입니다.
대규모 언어 모델(LLM) 보안, 전통적 ML 모델 보안, 그리고 AI 거버넌스를 중심으로
위협과 통제를 한국어로 정리·재구성합니다.

> 5G O-RAN의 `09-05 AI-ML Model Poisoning`과 개념이 겹칩니다. 일반 AI 보안 개념은
> 이 영역에 두고, 5G 특화 위협은 기존 위치에 두어 서로 **교차 참조**합니다.
