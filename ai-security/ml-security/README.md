# ML Security (머신러닝 보안)

전통적 머신러닝 모델의 보안을 다루는 하위 영역입니다.
데이터·모델 포이즈닝(Poisoning), 회피 공격(Evasion/Adversarial Example),
모델 추출(Model Extraction), 멤버십 추론(Membership Inference) 등을 정리합니다.

> MITRE ATLAS(공격 TTP)와 OWASP ML Security Top 10을 참조 축으로 삼고,
> 5G O-RAN의 `09-05 AI-ML Model Poisoning`과 교차 참조합니다.

## 예정 주제

- Adversarial ML 개요 (학습시점 vs 추론시점 공격 분류)
- Data Poisoning / Model Poisoning(Backdoor)
- Evasion (Adversarial Example)
- Model Extraction / Membership Inference / Model Inversion
- Federated Learning 공격
