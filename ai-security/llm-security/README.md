# LLM Security (대규모 언어 모델 보안)

대규모 언어 모델(LLM) 기반 애플리케이션의 보안을 다루는 하위 영역입니다.
프롬프트 인젝션, 민감정보 노출, 과도한 에이전시(Excessive Agency),
불안전한 출력 처리 등을 정리하며, **OWASP Top 10 for LLM Applications**와 연계합니다.

> 웹·API 보안의 OWASP 영역(`security-fundamentals/web-app-security/owasp/`)과 교차 참조합니다.
