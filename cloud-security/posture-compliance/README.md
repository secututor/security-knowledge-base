# Cloud Posture & Compliance (클라우드 보안 태세·컴플라이언스)

클라우드 보안 태세 관리와 **인증·규제 대응**을 다루는 하위 영역입니다.
CSPM(설정 오류 점검), 통제 매핑, 그리고 국내외 인증 대응을 정리합니다.

- CSPM / 설정 오류(Misconfiguration) 점검
- CSA CCM 통제 매핑
- **ISMS-P** (클라우드 이용기업 관리체계)
- **CSAP** (클라우드 서비스 제공자 보안인증)
- **ISO/IEC 27017** (클라우드 보안 통제 지침)

> 국내 인증 구분: ISMS-P=이용기업 / CSAP=CSP. 섞지 않고 각각 다룬다.
