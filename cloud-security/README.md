# Cloud Security (클라우드 보안)

클라우드 환경의 보안을 다루는 **최상위 영역**입니다.
컨테이너·쿠버네티스 등 클라우드 네이티브 인프라, 자격 증명·권한(IAM),
데이터 보호를 중심으로 위협과 통제를 한국어로 정리·재구성합니다.

> 5G의 NFV/클라우드 네이티브 위협(`5g-security/security-risks/08-nfv-cloud/`)과 개념이
> 겹칩니다. 일반 클라우드 보안 개념은 이 영역에 두고, 5G 특화 위협은 기존 위치에 두어
> 서로 **교차 참조**합니다.
