# Cloud Security Assessment (클라우드 보안 점검·평가)

클라우드 환경을 실제로 **점검·평가·검증**하는 방법을 다루는 하위 영역입니다.
이 영역이 지식베이스를 기술 설명에서 **실무 점검 기준**으로 끌어올립니다.

- 클라우드 보안 위험평가
- 설정 오류·취약점 점검 체크리스트 (CIS·CCM 기반)
- 클라우드 침투테스트
- 점검 결과 보고서 양식 / 개선 권고

> 콘텐츠 타입: `assessment` (rules-authoring §3.4 점검 템플릿). 각 점검 항목은 대응하는
> 통제(CCM)·설정 기준(CIS)·위협(ATT&CK) 문서와 상호 링크한다.
