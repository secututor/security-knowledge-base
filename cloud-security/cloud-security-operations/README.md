# Cloud Security Operations (클라우드 보안 운영)

클라우드 환경의 **로깅·탐지·대응**을 다루는 하위 영역입니다.
클라우드 침해는 IAM 오남용, 비정상 API 호출, 자격 증명 탈취와 밀접하므로,
이를 탐지하고 대응하는 운영 역량을 정리합니다.

- Cloud Logging Architecture / Cloud Audit Logs
- Cloud Threat Detection / SIEM 연동
- Cloud Incident Response / Forensics
- Cloud Detection Engineering

> MITRE ATT&CK Cloud Matrix(IaaS·SaaS·Identity Provider 등)와 직접 연계해 탐지·대응을 매핑한다.
