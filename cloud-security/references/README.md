# Cloud Security References (참조 정의집)

클라우드 보안 문서가 인용하는 표준·기관·프레임워크·인증의 **정의집**입니다.
각 위협·점검 문서의 참조 블록에서 이 정의를 인용합니다.

## 참조 프레임워크 (기준 버전)

| 코드 | 프레임워크 | 기준 버전 | 공식 출처 |
|------|-----------|-----------|-----------|
| CSA-CCM | CSA Cloud Controls Matrix | 4.1 (207 통제 / 17 영역) | https://cloudsecurityalliance.org/artifacts/cloud-controls-matrix-v4-1 |
| CIS | CIS Benchmarks | CSP·서비스별 최신판 | https://www.cisecurity.org/cis-benchmarks |
| NIST-80053 | *NIST SP 800-53* | Rev.5 | https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final |
| NIST-800144 | *NIST SP 800-144* | — | https://csrc.nist.gov/pubs/sp/800/144/final |
| NIST-800210 | *NIST SP 800-210* | — | https://csrc.nist.gov/pubs/sp/800/210/final |
| ATTACK-CLOUD | MITRE ATT&CK (Cloud) | 최신판 | https://attack.mitre.org/matrices/enterprise/cloud/ |
| ISO-27017 | *ISO/IEC 27017* | 2026 (Edition 2) | https://www.iso.org/standard/27017 |
| ISO-27018 | *ISO/IEC 27018* | 최신판 | https://www.iso.org/standard/76559.html |
| ISMS-P | ISMS-P (KISA) | 최신 고시 | https://www.isms-p.or.kr/ |
| CSAP | CSAP 보안인증 (KISA) | 2026 해설서 | https://www.isms-p.or.kr/ |

> 각 버전은 공식 링크에서 확인할 수 있다.
> 유료 표준(ISO)은 원문을 옮기지 않고 명칭·역할·공식 링크만 둔다.

## 세부 정의 문서
