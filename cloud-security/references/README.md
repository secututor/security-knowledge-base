# Cloud Security References (참조 정의집)

클라우드 보안 문서가 인용하는 표준·기관·프레임워크·인증의 **정의집**입니다.
각 위협·점검 문서의 참조 블록에서 이 정의를 인용합니다.

> 콘텐츠 타입: `reference` (rules-authoring §3.3). 새 참조를 임의로 만들지 않으며,
> 버전·발표일은 공식 출처로 확인한 값만 기재한다. 유료 표준(ISO)은 원문을 옮기지 않는다.

> **확인 출처/일자**: CSA CCM 4.1, ISO/IEC 27017:2026, CSAP 2026 해설서는 사용자가 공식 페이지에서
> 확인해 제공한 값(확인일 2026-11-12). 재검증은 각 공식 링크로 가능하다.
> "공식 발표 존재"와 "실제 최신판"을 구분하며, 발표일·게시일·정정일을 구분해 기록한다.
> "확인 예정" 항목은 공식 출처로 확정 후 버전을 채운다.
