# Web & Application Security (웹·애플리케이션 보안)

일반 보안 기초 중 **웹/애플리케이션 보안** 을 다루는 하위 영역입니다.
5G에 국한되지 않는 공통 지식으로, 웹·API·소프트웨어 계층의 위협과 통제를 정리합니다.

## 하위 영역

- **[OWASP](owasp/README.md)** — OWASP Top 10, API Security Top 10, ASVS 등 OWASP 프로젝트 기반 지식

> 널리 쓰이는 보안 프레임워크·체크리스트를 한국어로 재구성·해설합니다.
