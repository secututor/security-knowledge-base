# OWASP

**OWASP(Open Worldwide Application Security Project)** 는 웹·API·소프트웨어 보안을 위한
공개 자료와 체크리스트를 제공하는 비영리 프로젝트다. 이 영역은 대표 OWASP 프로젝트를
한국어로 재구성·해설하여, 애플리케이션 계층 위협을 이해하고 대응하는 배경 지식을 제공한다.

> 이 영역은 일반 보안 지식(`general`)이다. 5G 보안의 SBA/API 위협
> (`5g-security/security-risks/06-sba-security/`)과 개념적으로 겹치므로, 해당 문서에서
> 이 영역을 교차 참조할 수 있다.

## 출처 / 저작권 (중요)

- OWASP 자료는 대부분 **Creative Commons** 라이선스(프로젝트별로 CC BY-SA 등)로 공개된다.
  각 문서에서 참고한 프로젝트의 **출처와 버전(연도)** 을 명시한다.
  예: `Source: OWASP Top 10:2021.` / `Source: OWASP API Security Top 10 - 2023.`
- OWASP 로고·브랜드 자산은 사용하지 않고 **텍스트 출처 표기만** 사용한다.
- 원문을 그대로 복사·번역하지 않고 **핵심을 한국어로 재구성**한다 (rules-authoring §6).
- 그림이 필요하면 직접 Mermaid/SVG로 새로 그린다 (rules-diagrams).
