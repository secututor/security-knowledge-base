# OWASP Top 10

OWASP Top 10은 웹 애플리케이션에서 가장 영향이 큰 **10대 보안 위험**을 선정·해설하는
대표적인 인식 제고(awareness) 문서다. 수년 주기로 갱신되며, 현재 널리 참조되는 판은
**OWASP Top 10:2021** 이다.

> 이 영역은 일반 보안 지식(`general`)이며, 개념/방법론 중심으로 작성한다.
