# OWASP API Security Top 10

OWASP API Security Top 10은 **API 계층**에 특화된 10대 보안 위험을 다룬다.
전통적인 웹 Top 10과 달리 인증·인가(BOLA/BFLA), 리소스 소비, 비즈니스 로직 등
API 특유의 위협에 초점을 둔다. 현재 참조판은 **API Security Top 10 - 2023** 이다.

> 5G SBA(Service Based Architecture)는 NF 간 통신에 HTTP/2 + REST API(OAuth 2.0 토큰)를
> 사용하므로, 이 영역은 `5g-security/security-risks/06-sba-security/`의 API 관련 위협
> (SBA API Abuse, API Parameter Manipulation, OAuth Token Abuse 등)과 밀접하게 연결된다.
