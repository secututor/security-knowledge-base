# Security Operations Fundamentals (보안 운영 기초)

보안 운영의 **벤더·도메인 중립 공통 개념**을 다루는 하위 영역입니다.
클라우드/5G/AI 등 각 도메인의 특화 운영은 해당 영역에 두고, 여기에는 공통 이론만 남긴다.

- Security Logging 개념
- SIEM 개념·구성 요소
- Threat Detection 기초, Detection 사이클
- Incident Response 기초 (NIST IR 생명주기)
- Blue Team / SOC 개념

> **중복 경계**: 클라우드 특화 운영은 `cloud-security/cloud-security-operations/`에 둔다.
> 이 영역은 그 공통 기반(개념)만 제공하고 각 도메인이 참조한다. 콘텐츠 타입: `concept`.
